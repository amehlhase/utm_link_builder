# UTM Link Builder

This is a simple tool for Marketers to create a campaign URL consisting of the base URL as well as Campaign Source, Medium, Name and, optional, Campaign Content and Term.

## Features:

- Input base URL and UTM parameters
- Optional fields for content and term
- Instant UTM URL generation

## How to Run:

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python app.py
```
